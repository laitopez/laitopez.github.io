### Solve a simpler version of the problem

As much as I don't want to do duplicative work I have often encountered a services(s) that are too difficult to set up or get in a particular state. It can help to recreate a toy environment or project that is much simpler but that removes the friction and allows you to make progress to the final solution.

### Use a different language

Adittionaly, using a different or more familiar language may simplify things. I remember in my OS class the additional complexity of C was slowing me down dramatically. I was able to solve the problem in Python much quicker and get the end to end solution working after some iterating and then port it to C (before LLMS were a thing).

### Write a really well written explanation / bug report

Additiionaly, intend to send this to a more senior person who you might feel a bit embaresed to expose your lack of knowledge or understadning that you assume they have. This motivates me to write a really well, succinct explanation.

I often discover the solve in trying to be so detailed and succinct and don't need to message the more senior person.
