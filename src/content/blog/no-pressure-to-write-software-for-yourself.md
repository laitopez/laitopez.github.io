My past projects

### Leetcode planner thing

Around 2022 Leetcode was missing some features I was interested in. At the same time I read [this](https://jvns.ca/blog/2022/03/10/how-to-use-undocumented-web-apis/) cool post by Julia Evans on how to use another services api.

So, I sucked all my data out of Leetcode and displayed it in a web app in the format I was interested in.
